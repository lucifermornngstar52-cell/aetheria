# Aetheria — Lumenhold (Godot 4.2+)

Большая открытая карта для мобильной Anime MMORPG: столица Lumenhold со стенами, замком на холме, собором, гильдиями,
рынком и фонтаном; леса, луга, горы, река, озеро, 4 деревни, 5 сторожевых башен, 4 руины, 5 лагерей NPC, 2 пещеры,
3 арены боссов, мосты, дороги и тропы. Мир 2048 × 2048 м (≈ 4 км²), оригинальный (не копирует локации SAO).

## Как открыть
1. Godot **4.2 или новее** → *Import* → `project.godot`.
2. Первый запуск редактора импортирует ~250 файлов GLB/PNG (1–3 минуты) — это нормально.
3. Откройте `scenes/main.tscn`: карта сразу видна во вьюпорте (скрипт `world_builder.gd` помечен `@tool`).
   Растительность в редакторе строится вокруг точки появления, при игре — стримится вокруг камеры.
4. **F5** — игра. Управление: WASD / стик на экране, правая кнопка мыши или касание справа — камера,
   Space — прыжок, Shift — бег, **F** — режим полёта (быстрый осмотр карты), кнопки Map / Quality / +2h на экране.

## Что внутри
| Путь | Содержимое |
|---|---|
| `world/terrain/chunk_X_Z.glb` | 64 чанка рельефа 256 м, по 4 LOD (4/8/16/32 м) + юбки против трещин + вода. Splat-веса в цвете вершин |
| `world/structures/struct_X_Z.glb` | Постройки по блокам 128 м: `Landmarks`, `HousesNear` (полная геометрия), `HousesFar` (LOD1), `Occluder-occonly` |
| `world/prop_library.glb` | Деревья (дуб, берёза, сосна, ель, сакура, мёртвое), кусты, папоротник, цветы, камни, трава, тростник — по 2–3 LOD |
| `world/data/instances.bin` | ~53 тыс. инстансов (MultiMesh-буферы), стримятся по расстоянию до камеры |
| `world/data/heightmap.f32` | Карта высот 513×513 (шаг 4 м) → коллизия `HeightMapShape3D` и `height_at(x, z)` |
| `world/world_manifest.json` | Чанки, диапазоны LOD, POI (точки подземелий/боссов/лагерей), колайдеры, огни, дороги, точка появления |
| `shaders/` | Рельеф (5 слоёв + снег), вода, листва с ветром, небо с облаками и звёздами |
| `scripts/` | `world_builder.gd`, `player.gd`, `day_night.gd`, `hud.gd`, `grass_field.gd` |

Все объекты — настоящая 3D-геометрия (стены, крыши, окна, двери, стволы, ветви, кроны, камни, мосты). Плоских картинок вместо объектов нет.

## Мобильная оптимизация
- Рендерер **Mobile** (Vulkan). Для старых устройств: Project Settings → Rendering → Renderer → `gl_compatibility`.
- LOD: рельеф — 4 уровня через `visibility_range`; дома — `HousesNear`/`HousesFar`; растительность — 2–3 уровня, ячейки 96 м.
- `Occluder-occonly` в блоках города → `OccluderInstance3D` (включено `occlusion_culling`).
- Один общий набор материалов (19 шт.), вершинные цвета вместо уникальных текстур, ~10 текстур 128–512 px.
- Кнопка **Quality** (Low/Medium/High) меняет дальности LOD, плотность растительности и 3D-масштаб.
- Тени: 2 каскада, дальность 140 м. Динамических огней немного (~14), с `distance_fade`.

## Экспорт на Android / iOS
В пресете экспорта → *Resources* → *Filters to export non-resource files*: `*.json, *.bin, *.f32, *.u8`
(иначе манифест и данные не попадут в сборку). Включите ETC2/ASTC (уже включено в `project.godot`).

## Расширение карты
Мир строится по координатам: чанки адресуются как `chunk_X_Z`, манифест перечисляет их явно. Восточный и южный края открыты
(дороги уходят за карту) — новые чанки можно добавлять рядом, высоты на краю продолжаются естественным шумом.
Точки для геймплея: группы `poi_cave`, `poi_boss`, `poi_camp`, `poi_village`, `poi_tower`, `poi_ruins`, `poi_landmark`, `spawn`.

## Честно о границах
- Проект собран процедурным генератором и **не запускался в Godot в среде, где он создавался** (там нет движка).
  GLB проверены собственным валидатором, GDScript/шейдеры написаны по документации 4.2 — возможны мелкие правки при первом запуске.
- Это не ручной арт уровня Genshin/SAO: текстуры процедурные, формы упрощены. Это структурно полная, оптимизированная основа,
  которую арт-команда может дорабатывать (заменять модели/текстуры, не трогая раскладку и данные).
